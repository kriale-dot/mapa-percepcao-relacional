# mapa-relacional-web

Frontend da plataforma Mapa de Percepção Relacional.

A implementação será iniciada na Etapa 1 com React, Vite e Tailwind CSS v4.

A aplicação deverá separar claramente:

- site institucional público;
- área do participante;
- área profissional.
